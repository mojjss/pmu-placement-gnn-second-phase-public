# Saved examples

The manifest lists twelve existing cases: one intact and two single-outage cases per IEEE14/57/118/300 system. They belong to the paper datasets and are not claimed unseen. NPZ inputs retain original bytes. Expected JSON outputs serialize existing labels and previously saved corrected GNN records where available; no missing prediction is invented.

Run `pmu-gnn saved --example IEEE14/line_0_0` for saved output only. For an explicitly authorized new Greedy calculation use the greedy command in docs/REPRODUCING.md with a fresh example_runs/ directory. The full datasets remain under data/, separate from these demonstrations.
